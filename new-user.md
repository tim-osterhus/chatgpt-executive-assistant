# Set up your executive assistant

If you want ChatGPT to help you set this up, copy and paste this file into [ChatGPT](https://chatgpt.com) and ask it to walk through setup with you.

These steps get the assistant running on your computer. The assistant will guide everything after that.

## 1. Download this folder from GitHub

1. Click **chatgpt-executive-assistant**, the repository name near the top of this GitHub page.
2. Click the green **Code** button above the file list.
3. Click **Download ZIP**.
4. Open your computer’s **Downloads** folder.

## 2. Unpack the download

Follow the steps for your computer.

### Mac

1. Double-click the downloaded ZIP file, unless your browser already unpacked it.
2. Rename the extracted folder to **chatgpt-executive-assistant**.
3. Move that folder into **Documents**.

### Windows

1. Right-click the downloaded ZIP file.
2. Choose **Extract All…**.
3. Click **Extract**.
4. Open the extracted location.
5. Find the folder containing **AGENTS.md**, **README.md**, and **SETUP.md**.
6. Rename that folder to **chatgpt-executive-assistant**.
7. Move that folder into **Documents**.

Keep this folder in Documents. It will hold your assistant’s instructions and personal notes.

## 3. Install the app and sign in

OpenAI’s desktop app is called **ChatGPT**. You will select **Codex** inside the app.

### Mac with Apple Silicon

Check **Apple menu → About This Mac** for your chip. Apple Silicon chips have M-series names, such as M1.

1. [Download the official Mac installer](https://persistent.oaistatic.com/codex-app-prod/Codex.dmg).
2. Open the downloaded **Codex.dmg** file.
3. Drag the app into **Applications** in the installer window.
4. Open the installed app from **Applications**.

### Windows

1. [Download the official Windows installer](https://get.microsoft.com/installer/download/9PLM9XGG6VKS?cid=website_cta_psi).
2. Open the downloaded installer.
3. Follow the installer’s prompts.
4. Open the installed app from the **Start** menu.

For Intel Macs or other computers, check available options in [OpenAI’s installation guide](https://learn.chatgpt.com/docs/quickstart?setup=app).

Then:

1. If you need an account, [create one in ChatGPT](https://chatgpt.com).
2. Sign in with your ChatGPT account.
3. Return to the desktop app after signing in.

## 4. Open your assistant folder

1. Select **Codex** from the **ChatGPT** dropdown.
2. Open **Projects**.
3. Create a local project named **Executive Assistant**.
4. Open that project’s menu.
5. Select **Edit project**.
6. Select **Add folder**.
7. Choose **Documents → chatgpt-executive-assistant**, the folder containing **AGENTS.md**.
8. If several folders are attached, point to this folder and select **Make primary**.
9. Open a **New chat** inside **Executive Assistant**.

If project creation already attached this folder, skip steps 4–8. [OpenAI’s project guide](https://learn.chatgpt.com/docs/projects) shows how attached folders work.

## 5. Start the guided setup

Copy this message into the new chat and send it:

> Start setup. Read SETUP.md and walk me through it. I am new to this, so offer choices and explain one step at a time.

The assistant will ask a few questions, help connect something useful, and complete a first task with you.

Come back to the **Executive Assistant** project whenever you want help. Setup will recommend connecting your phone through Remote and creating or reusing one dedicated **Executive Assistant Voice** task in that project. Keep Live Voice in that task. Voice uses Astra Light for conversation and quick self-contained requests, then routes substantial work to the existing Astra High orchestration task. Typed requests and dictation work in either task. Phone and Live Voice remain optional, and the assistant will guide you through the choice.
