# Deferred Context Mill integration

Context Mill is a possible optional source of curated project context. Its usefulness for this workflow is still being evaluated. No working connection, installable release, background upkeep, or required dependency is established by this template.

The core assistant and outbound calling use existing project files and selected knowledge sources. Keep using those routes. Do not install or activate Context Mill during current setup.

When the integration is resumed, connect an independently configured service through its supported reader interface. Verify the actual client/account, permitted collections, provenance and revision dates, publication freshness, restricted access, revocation, and reconnect. Map collections to selected assistant projects explicitly. A connection does not mean every project is covered.

The coordinator may then use allowed records to prepare a call's context. Provider access to those records needs its own applicable authorization. Context Mill should remain independently disableable and unnecessary for calls. Never bypass a restricted collection by silently reading a broader local source.

Keep call receipts and execution state in their existing systems. Context Mill v1's described reader contract does not provide upstream file writeback or MCP note capture. Recheck its current interface and independent installation before implementing this adapter.
